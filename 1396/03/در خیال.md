# در خیال

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">در خیالم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">تویی باز در کنارم.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">مویت را می‌بویم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">رویت را می‌بوسم.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دست تو در دست من،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">پا به پا می‌رویم.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دشت به دشت،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">شهر به شهر،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">از کوه‌ها می‌گذریم.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">آنگاه به یاد می‌آوریم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">همصدا از بر می‌خوانیم:</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دوستت می‌دارم، ای یار دیرینم</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دوستت می‌دارم، با تو من می‌مانم...</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank"> </a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">آه خدایا،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">کِی می‌شود حاصل؟</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">مهرش بر دل،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">یادش در خاطر.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">می‌خواهم تا باز هم پر گیرم سوی تو.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">رویت را باز بینم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">جا گیرم در آغوش تو.</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">آنگاه به یاد آوریم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">بی صدا با هم بخوانیم:</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دوستت می‌دارم، ای یار دیرینم،</a>

<a href="https://soundcloud.com/sasan-farid/fjonsqbjjin2" target="_blank">دوستت می‌دارم، تو ای آرام جانم...</a>
